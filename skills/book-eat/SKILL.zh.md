# book-eat · 吃一本书（中文镜像版）

> **维护声明**：英文 `SKILL.md` 是规范真相源，本文件是其中文镜像。改 skill 时两份一起改；若失同步，以英文版为准。

六步流水线编排器：①全文缓存 → ②定纲 → ③精读 → ④归档 → ⑤卡片 → ⑥看板发布。
**状态机可重入**：对同一本书任何时刻再次调用，从断点继续，绝不重做已完成工作。
工作目录一律是**库根目录**（拥有 `sources/` 的仓库）。

## 库结构与自举（第0步最先做）

预期结构（缺失时第0步自动创建）：

```
sources/            投放新书（.pdf / .epub）
books/<书>/ocr/     pages/  full.txt  toc.txt  quality_report.txt   ← 原始机器层，永不回写
books/<书>/         README.md（定纲）、精读-NN、摘要-NN
topics/<区>/        主题笔记——区目录按需建，永不预设
cards/              复习卡片（Q/A）
INDEX.md            进度看板
READER.md           可选：读者品味档案——约束一切笔记/卡片的产出风格（见③④⑤）
```

自举规则：
- 库根缺 `tools/run_ocr.py`（抽取）或 `tools/quote_check.py` / `tools/check_source.py`（核验门禁）→ 从本 skill 的 `tools/` 目录拷贝
- 缺 `sources/ books/ cards/ topics/` 或 `INDEX.md` → 创建；`INDEX.md` 用 `scaffold/INDEX-template.md` 播种
- 库 `CLAUDE.md` 缺知识规格 → 追加 `scaffold/CLAUDE-snippet.md`

## 第0步 · 状态检测（每次调用必做）

| 现状 | 下一步 |
|---|---|
| sources/ 有新书（.pdf/.epub）且 books/ 无此书目录 | 阶段① |
| books/<书>/ocr/full.txt 缺或不完整 | 阶段①续跑 |
| 无 books/<书>/README.md（定纲） | 阶段② |
| 定纲在，但用户从未确认过分级表 | **⛔ 确认门** |
| 精读/摘要笔记未齐（对照分级表） | 阶段③④⑤ |
| 流水线全绿但 html/ 未重新发布 | 阶段⑥ |

多书并存或书名不明 → 列出 sources/ 与 INDEX 看板让用户选。

## ① 全文缓存

```bash
timeout 480 python3 tools/run_ocr.py <书名> sources/<pdf或epub>   # 重复执行直到输出 DONE
```

- 支持 **.pdf / .epub**；其他格式（mobi/azw3/djvu…）脚本会明确报错 → 先转 epub/pdf 再入库
- 脚本自动检测：有文字层 → 直抽（秒级，PDF/EPUB 同理）；无 → RapidOCR（约8秒/页，EPUB 合成页同路径）
- **后台长任务约10分钟会被系统杀：必须 timeout 分块跑**（断点续跑，已完成页自动跳过；按自家主机后台被杀上限调整 timeout 值）
- 产物：`pages/` 逐页、`full.txt` 带页标记、`toc.txt`（目录→起始页，垃圾书签自动弃用）、`quality_report.txt`（仅 OCR 路径）
- 页标记格式：`===== PDF第N页 =====` / `===== EPUB第N页 · 章节名 =====`（EPUB 合成页码每本固定可复现）。笔记书证出处两者皆可：**书+页** 或 **书+章节**
- 完成后读 quality_report.txt → 标出低置信页，作为视觉复核候选
- **源完整性门（两条路径都要，②之前）**：`python3 tools/check_source.py books/<书>/ocr/full.txt` —— 抓文本层混入的 NUL 字节与**标题页空洞**（文字层 EPUB 可能整章正文静默缺失，此后该章所有引文都无源而无人察觉）。逐条 ⚠ 在定纲前解决：良性薄页（版权页/纯图版）→ README 注记；真缺章 → README 登记源缺陷，该章内容此后一律按无源对待

## ② 定纲 → ⛔ 确认门

1. 分块通读 full.txt（配合 toc.txt）；判定类型：现代书 → 分级处理 / 典籍 → 四层精注
2. 写 books/<书>/README.md：基本信息、全书纲要、**章节分级表**（核心精读/次要摘要/跳过）、与 ROADMAP 的关系（若库有）
3. INDEX 看板更新①② → commit + push
4. **⛔ 必停（REQUIRED STOP）：把分级表呈给用户，明确等待确认或调整。未获确认，禁止进入③④⑤⑥。**

> 为什么停：分级是编辑判断，决定全部下游工作量与笔记结构，错了=精读归档全废再返工。以下理由**不成立**，已被实测驳回：
>
> | 套口 | 现实 |
> |---|---|
> | "约定可推导，无需问" | 拆几篇精读、跳哪些章，约定推不出来，是编辑判断 |
> | "问一次不值得打断" | 一次打断换的是整本书的方向批准，成本极低 |
> | "先做完一起看更高效" | 做完=已花掉全部 token 和提交历史，返工最贵 |

## ③④⑤ 精读 → 归档 → 卡片

- **严格按已确认的分级表**产出 精读-NN / 摘要-NN；大书跨会话，每完成 1–2 篇即 commit+push 并更新 INDEX 进度
- **读者品味对齐（可选）**：库根可放 `READER.md`（读者品味档案：这个读者怎么读、已认可的输出范式、档案自身的修订规则）。存在则精读/摘要/卡片一切产出前必读对照；会话中的提炼风格类反馈按档案自身修订规则回写该文件
- **质量门（写侧为纲，强制）**：
  - *落笔前*：引文一律**从 `ocr/full.txt` 复制，绝不凭记忆默写**。缓存里找不到的段落＝不可引用——要么在缓存中定位，要么按通用知识写并标 **⚠未验证**
  - *落笔后、提交前*：`python3 tools/quote_check.py books/<书>/ocr/full.txt <笔记文件...>` —— 每条 MISS 当场归因三选一：OCR/异文噪声（开页核对确认）、译引（外文书：回原文核对译忠实）、**⚠未验证**＋原因。绝不带未归因 MISS 提交
  - *读侧（缓存可疑处）*：quality_report 低置信页、古籍木刻页、表格图版 → 回原页图像核对；有图像理解工具（视觉 MCP 等）→ 直接核对页图像；没有 → 产出引文/低置信页清单并标 **⚠待人工复核**；绝不静默跳过
  - 考据数据（年代/人名/版本/数目）同规则：先对缓存，缓存可疑升级页图，再不行标 ⚠
- 归档 topics/ 对应区、回填书证（升级 ⚠未验证 → 已书证）、扩术语库、cards/ 建卡（含难度 1–5）

## ⑥ 看板 + 可选发布

- INDEX 全绿**且卡覆盖成立**：凡有精读笔记的书在 `cards/` 有对应卡（有笔记无卡 ≠ 全绿——要么补卡，要么在该书 README 记录成文豁免及原因）→ commit + push
- 发布（可选，**由各库自定义**）：库根若提供 `tools/publish.sh` 则在此执行——该脚本由库主人自写（HTML 构建/部署等，随你的环境定），实际行为建议写进该库自己的 CLAUDE.md。无此脚本则⑥止步于 INDEX 提交

## 知识规格（一切写作不可违反）

- **来源标注**：一切知识标出处（**书+页** 或 **书+章节**；EPUB 合成页码每本固定可复现，页码引用稳定）
- Claude 通用知识而非已读书籍者标 **⚠未验证**，待书证后回填
- 主题笔记四件套：白话定义 → 出处 → `[[关联术语]]` → 易混辨析
- **典籍类书**（古籍点校本）→ 四层精注逐章一条：①原典摘录 ②白话译文 ③考据（版本/文字/史实，存疑标 ⚠）④义理（思想脉络与后世影响）；现代书 → 分级处理（核心精读/次要摘要/跳过）
- 复习卡片：Q/A + 出处 + 难度 1-5 + 状态
- 答疑中反复出现的盲点沉淀进 `faq/`
- `ocr/full.txt` 是原始机器输出层，**永不回写**——修订只落笔记层，保持审计可回溯

## 硬规则

- `ocr/full.txt` 永不回写，修订只落笔记层
- 每阶段完成即 commit + push
- 原书文件与 OCR 缓存受版权保护——**永不推到公开远程**（库转公开前必须 `git filter-repo` 清历史）
- 依赖缺失自动补装：`pip3 install --user --break-system-packages pymupdf rapidocr-onnxruntime`（有 sudo 或 venv 的主机去掉 `--break-system-packages`）

## Red Flags（出现即停，自查）

- "分级表先不问了，做完一起看" → 违反确认门，回到②
- OCR 长任务裸跑不加 timeout → 10 分钟被杀白跑
- 精读引文直接信 OCR 未回查 → 违反质量门
- **「这段经典我熟，凭记忆写引文」** → 写侧门正是为此而设；从缓存复制或标 ⚠未验证
- **quote_check 的 MISS 不开页核对就当『OCR 噪声』放行** → 门的意义就是逼你去看一眼；未归因 MISS 正是幻觉/颠倒引文存活的原因
- **文字层 EPUB 没跑 check_source 就当完整** → 章节正文可能整段缺失，缺口里的每条引文都无源
- **图版覆盖靠「图N」连续性或章节页码窗扫描来宣布** → 附录/表格内木刻挂的是表号（非图N题注）、且常住在章节窗之外；应改查「讲义文本含图指涉（132图计数/图版/图样）而嵌图为零」——引用存在性≠覆盖性
- 跳过第0步状态检测直接从头跑 → 可能重做已完成工作
- 拿到 .mobi/.azw3 直接塞 sources/ 等流水线跑 → ①只认 pdf/epub，先转换
